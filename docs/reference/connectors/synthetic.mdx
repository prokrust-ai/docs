Use the synthetic connector to test a table with repeatable data. It generates CSV files inside the cluster. It requires no source credentials.

## Releases

Choose the release installed in your cluster. [Synthetic 1.1.0-rc.1](/reference/connectors/synthetic/1.1.0-rc.1/)

## Connection

The connection sets the number of files, the rows per file, and the seed for the values. [Connection fields in 1.1.0-rc.1](/reference/connectors/synthetic/1.1.0-rc.1/#connection-fields)

## Table selector

The selector identifies the generated dataset that a table reads. [Table selector in 1.1.0-rc.1](/reference/connectors/synthetic/1.1.0-rc.1/#table-selector)
