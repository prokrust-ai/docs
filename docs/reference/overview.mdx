## Public API

Use the [API reference](/reference/api/) to find a method, check its fields, and adapt an example. [GetTable](/reference/api/get-table/) reads one table. [HTTP endpoints](/reference/api/http/) cover browser sessions, performance captures, model inference, health, and operator metrics.

## Kubernetes resources

Find a kind under the API group in your manifest's `apiVersion`. These definitions come from <code>{releases.crds.chart}</code> <code>{releases.crds.version}</code>. Connector kinds are available when the operator enables the corresponding CRD feature.
