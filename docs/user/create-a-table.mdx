Register data from an existing connection. The saved table identifies the source data, its columns, and the column that identifies each row.

## Before you begin

- Use a workspace where you can access the connection and create and read tables. [Prepare a workspace](/operator/workspaces/)
- Choose the object, prefix, or source table to read. The connection determines what you can access. The selector narrows that scope to the data for this table. [Source selector examples](#source-selector)
- Identify a column with a unique, non-null value in each row. Determine the names and types of the other columns you need.

For a first run without an external source, use the [synthetic table quickstart](/user/synthetic-table/).

## Create the definition

<ActionTabs>
<TabItem value="ui">

1. Select your workspace in the Prokrust app. Open **Data → Tables → Create Table**.
2. Enter an unused **Table name**.
3. Under **Source and discovery**, select **Connection type**. Select **Connection**.
4. Choose **Selector version** if the app shows this field. Use the source picker if available. Otherwise, enter the source selector fields.
5. Use **Add column** for each column. Set the name, physical type, semantic role, and feature flag.
6. Under **Key and feature time**, select the primary key. Choose the feature time policy. For `RowEventTime`, select the event-time column.
7. If the source needs parsing or conversion, open **Conversions and source mappings**. Enter the read options and mappings for that source.
8. Select **Review Table**. Check the source and columns. Select **Create Table**.

## Verify the stored definition

<ReadTable />

Check the connection name, selector, and primary key in the returned definition. These fields confirm which data the table will read and how it will identify each row. To read the source data, create a snapshot. [Tables and snapshots](/user/core-concepts/#tables-and-snapshots)

## Table fields

| Field | How to choose the value |
| --- | --- |
| `apiVersion`, `kind` | These identify the Kubernetes resource to create. Use `data.prokrust.ai/v1beta1` and `Table` for this table schema. The curl method identifies the resource type through `CreateTable`. |
| `metadata.name` | `metadata` holds the resource identity. Give the table an unused name in the workspace. Use this name to retrieve it. The curl request uses `name` for the same value. |
| `spec` | The definition that Prokrust stores for this table. Set the source to choose the rows. Set the columns, key, and time policy to describe them. |

### Source selector

`spec.source` has two required parts. `connectionRef` identifies the connection that provides access. `selector` identifies which data the connector should read through that connection.

| Field under `spec.source` | How to choose the value |
| --- | --- |
| `connectionRef.apiVersion`, `connectionRef.kind`, `connectionRef.name` | Copy `apiVersion`, `kind`, and `metadata.name` from the connection in your workspace. Together they identify that resource. Choose a different connection if the data is in another bucket or project. |
| `selector.schemaVersion` | Use a selector version supported by the installed connector. This determines the keys and values it accepts in `config`. Change it when you adopt a different selector schema. |
| `selector.config` | Set the connector-specific fields that locate your data. Change them to select another source through the same connection. The connector's release and its selector schema version are separate values. |

**Amazon S3.** For one object, use these fields in `spec.source.selector.config` with selector schema `v1`.

```yaml
kind: object
path: exports/orders.parquet
```

`kind: object` selects one object. `path` is its key in the connection's bucket, including the configured prefix. Change `path` to read a different object. To read files under a common prefix, set `kind` to `prefix` and use a path such as `exports/orders/`.

**BigQuery.** For one physical table, use these fields in `spec.source.selector.config` with selector schema `v1`.

```yaml
kind: table
dataset: sales
table: orders
```

`kind: table` selects a physical table. `dataset` names one of the datasets the connection can read. `table` names the table within that dataset. To read returns from the same dataset, change `table` to `returns`. To use a table from another allowed dataset, change `dataset` too.

For the generated event dataset, see the [Synthetic 1.1.0-rc.1 selector](/reference/connectors/synthetic/1.1.0-rc.1/#table-selector).

### Columns, key, and time

| Field | How to choose the value |
| --- | --- |
| `spec.columns`, `spec.columns[].name` | Add an entry for each column you want the table to expose. Use the source column name when you read it directly. Use a source mapping if the input and output names differ. |
| `spec.columns[].physicalType` | Sets the column's data type after ingestion. For a text identifier, use `Utf8`. For a signed 64-bit integer identifier, use `Int64`. |
| `spec.columns[].semanticType` | Sets the column's role. Use `Id` for a key. Use `Numerical` for a measurement, such as an amount, or `Timestamp` for an event time. |
| `spec.columns[].feature` | Set `true` to include a supported column as a model feature. The template uses `false` because the key only identifies the row. |
| `spec.primaryKey` | Enter the name of the `Id` column that uniquely identifies a row. For a table of order lines, use a unique line identifier if the order identifier repeats. |
| `spec.featureTimePolicy`, `spec.eventTime` | Use `Static` for time-independent features and omit `eventTime`. Use `RowEventTime` when Prokrust must filter rows by event time. Set `eventTime` to the name of a `Timestamp` column with physical type `TimestampNanosecondUtc`. |
| `spec.ingestion` | Omit this field for Parquet columns that already have the required types. Add it to parse CSV input, map a source column to another name, or convert a source value. [CSV column mappings](/user/synthetic-table/#csv-column-mappings) |

[Supported column types and roles](/reference/kubernetes/data.prokrust.ai/v1beta1/table/#columns)
